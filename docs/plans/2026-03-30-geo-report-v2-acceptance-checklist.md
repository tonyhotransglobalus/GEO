# GEO Report V2 Acceptance Checklist

## Purpose

Use this checklist before promoting V2 from shadow mode to client-ready output.

## Checklist

- `decision-grade` thresholds are documented and reviewed
- the leadership summary stays short and plain-English
- a non-technical reviewer can identify the top issue, top action, trust level, and key limitation
- a named promotion owner signs off on the run
- the V1 versus V2 comparison outcome is recorded
- shadow-mode runs preserve prior comparison artifacts
- the stable compatibility markdown copy is not overwritten by shadow runs

## Outcome

- `pass`: all checklist items are satisfied and the run is ready for promotion review
- `conditional pass`: the run is useful for shadow comparison but needs follow-up before client delivery
- `fail`: the run is not yet ready for promotion
